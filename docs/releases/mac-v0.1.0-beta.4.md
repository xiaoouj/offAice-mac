新增可在软件内自行填写的 API 连接。适用于 Apple Silicon、macOS 13+。

- 新增“设置与连接 → 连接与版本 → 添加 API 连接”，填写名称、服务地址、API Key、默认模型及输出 Token 上限。
- 支持 OpenAI Chat Completions 兼容接口、阶跃等自定义服务，以及 Gemini 原生 Generate Content。提供服务地址预设，可同时保存多条独立连接并创建人物卡。
- 支持读取模型列表、手动模型、流式回复、历史续聊、取消与团队讨论；API 成员不执行命令或读写文件，暂不支持图片与工具调用。
- 密钥通过本机系统凭据加密保存，界面不回显原文；变更地址或协议需重新输入密钥，不携带密钥跟随 HTTP 重定向。
- 保存及连接检查不发送生成请求。API 费用按服务商项目计算，不直接使用聊天产品的订阅额度。生成请求不会自动重试，截断结果保持待核对。
